# LiquidGlass 4.0 — 物理手感液態沙漏番茄鐘 ＋ 速度連續型 120fps 流體動畫架構

專為 **iPhone 18 Pro（120Hz ProMotion / 窄版實體動態島挖孔 `88×32 pt`）** 打造的旗艦級物理液態沙漏番茄鐘與光學實驗室，完整相容 GitHub Actions 雲端編譯與免費 Apple ID 側載（Impactor，零 App Groups 依賴）。

## 4.0 核心旗艦升級

1. **物理手感液態沙漏番茄鐘（首頁「專注」分頁）**：
   - **GPU 雙腔體流體 SDF 與表面張力斷裂（Pinch-Off）**：單通道 120fps Metal Shader 即時運算雙腔體高折射玻璃外殼、雙層菲涅耳高光、RGB 彩虹色散、毛細拉絲斷裂水珠與尾隨微水珠（Plateau-Rayleigh Satellite）、下腔撞擊水波紋及底部焦散光暈（Caustics）。
   - **棘輪光學時間環（5 ～ 60 分鐘）**：沿外圈軌道滑動時化為高透光凸透鏡放大鏡水滴並依切線速度果凍拉伸，每跨越 1 分鐘觸發精密機械棘輪微震，放開後以阻尼彈簧吸附整數分鐘。
   - **CoreMotion 重力液面傾角 ＋ 翻轉手機啟動／重置**：液面隨手機傾角即時晃動，將 iPhone 倒轉或翻面即可物理旋轉沙漏 180° 並啟動／重置計時；專注（極光藍稜鏡）與休息（晨曦暖金森綠）大氣色溫 120fps 流體漸變。
   - **三組專屬 `CoreHaptics` 物理波形**：精密機械棘輪聲、極輕柔水珠共鳴（控制中心可獨立開關）、番茄鐘完成三連音液態諧振波。
2. **速度連續型 120fps 物理引擎 ＋ Apple 原生雙段式底部導覽列**：
   - 固定 `dt = 1/120` 動量連續彈簧解算器（`Spring1D` / `Spring2D`），飛行或回彈途中再次按住零座標跳變。
   - 左側 78% 主膠囊（`專注`、`探索`、`音樂`、`控制`）＋ 右側 `10pt` 間隔獨立圓形玻璃球（`工坊`）；Y 軸嚴格鎖死，靜止時顯示 `#38BDF8` 亮天藍選中態，按住滑動時膨脹為高折射凸透鏡水滴、底板自動變透並放大色散經過的圖示。
   - **Zen 極簡沉浸模式**：計時中點擊空白處或從頂部挖孔下拉，周邊介面以流體縮放隱退，僅留純淨懸浮沙漏與呼吸光暈。
3. **iPhone 18 Pro 雙層動態島整合（零 App Groups）**：
   - 前景純黑 `#000000` 硬體挖孔液態觸角磁吸融合；背景與鎖定畫面由 `ActivityKit` + `Text(timerInterval:countsDown:)` 接手每秒精準倒數、迷你沙漏進度環與 `LiveActivityIntent` 互動按鈕（暫停/繼續、重設、切換專注/休息）。
